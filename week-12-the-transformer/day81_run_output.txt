5. GREEDY DECODING, AND WHY ONE PASS IS ENOUGH IN TRAINING
======================================================================
The untrained model writes 9 tokens for each of the 300 fixed 8-digit COPY sequences, one at a time, feeding each token back in. Then the tokens it wrote are given to the decoder all at once (GO plus the first 8), in ONE pass, as in training. The causal mask (Day 80) says the two must agree.

largest difference between the two: 2.66e-15; same tokens chosen: True
untrained model: exact match 0.000, token accuracy 0.040; its most written token is 9 (0.573 of all tokens)

6. WHAT A FORWARD PASS COSTS AS SEQUENCES GROW
======================================================================
One forward pass (teacher forcing), batch of 32, source and target of n digits; best of 5 timings of 10 passes, matrix library on one thread. Attention compares every position with every position, so part of the work grows like n squared. Only ratios within this run are meaningful.

   n  ms per pass  vs n = 8
   8         1.84      1.00
  16         4.42      2.41
  32        11.76      6.40
  64        44.85     24.41
(doubling n would double the cost if everything grew like n, and quadruple it if everything grew like n squared)
