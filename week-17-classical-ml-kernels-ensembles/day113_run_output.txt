2. WHAT MAKES A VALID KERNEL -- no negative eigenvalues
======================================================================
  linear                                : smallest eigenvalue -1.093e-12, largest +3.203e+03, negative ones 0
  polynomial, degree 2                  : smallest eigenvalue +2.823e-01, largest +4.298e+04, negative ones 0
  RBF, gamma 0.03                       : smallest eigenvalue +7.107e-04, largest +2.277e+02, negative ones 0
  tanh(x.z - 1), a popular non-kernel   : smallest eigenvalue -7.054e-03, largest +3.000e+02, negative ones 62
  minus the distance |x - z|            : smallest eigenvalue -9.036e+02, largest +8.344e+01, negative ones 1
a kernel matrix must be positive semi-definite (no negative eigenvalues): then it is a table of real dot products, and the dual problem has one best answer
