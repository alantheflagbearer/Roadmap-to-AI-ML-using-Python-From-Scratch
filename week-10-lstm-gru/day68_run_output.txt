======================================================================
6. WHAT COMES NEXT
======================================================================
A bidirectional layer can only be used when the whole input is available before any output is needed -- true for tagging a finished sentence, not for writing a sentence word by word. Day 69, the week's build, uses both kinds: an ENCODER that reads a whole input sequence (and may read it both ways), and a DECODER that writes an output sequence one token at a time, left to right.
