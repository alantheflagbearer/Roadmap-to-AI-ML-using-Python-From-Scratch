1. TEXT -> NUMBERS -- tokenize, build a vocabulary, encode, pad
======================================================================
A network multiplies numbers; it cannot multiply words. Each sentence is split into tokens, each token is replaced by an integer id from a vocabulary built on the training sentences only, and every sentence is padded with id 0 to a common length so a batch fits in one array.

sentences: 3000  (positive 1500, negative 1500)  sources: amazon 1000, imdb 1000, yelp 1000
split: train 2000, validation 400, test 600  (positive fraction 0.501 / 0.517 / 0.483)

3. THE ORDER-BLIND BASELINE -- bag-of-words logistic regression
======================================================================
Each sentence becomes a vector of 0s and 1s: which vocabulary words appear in it. Word ORDER is thrown away. A softmax regression on those vectors is the bar the RNN has to clear: anything the RNN adds must come from order.

best validation accuracy 0.772 at epoch 314; test accuracy there 0.817  (chance = 0.500; 600 test sentences, so one standard error is roughly 0.02)
most negative words: bad, poor, not, worst, slow, don't, terrible, then, waste, no

7. WHAT COMES NEXT
======================================================================
Every piece needed to run an RNN on real text now exists and is checked: tokens, ids, padding, an embedding table, masking, a many-to-one readout, clipping. What 2,000 sentences and a vanilla RNN did NOT deliver is a use for word order -- the numbers above are the evidence. Day 62 changes the output side: many-to-many, one label per word instead of one per sentence, where position is the whole task. Week 10 changes the cell: the LSTM (Day 63).
